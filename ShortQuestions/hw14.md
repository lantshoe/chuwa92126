An object is a row data.

Controller receives the request and extracts the student ID.
Controller calls the Service layer, which handles business logic, such as validating the student and checking permissions.
Service then calls the Repository, which provides data access methods through Spring Data JPA.
Hibernate, as the JPA implementation, translates the query into SQL and maps database results back into Java entities.
